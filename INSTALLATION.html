E*Trade MCP Installation

Complete Exhaustive Setup Guide • Version 1.0 (2026)

1

Download & Prepare Code

First, we create a dedicated workspace and clone the repository. Ensure you have the GitHub CLI (gh) installed.

# Create directory
mkdir -p $HOME/mcp
cd $HOME/mcp

# Clone the repository
gh repo clone shahid11885/etradeMCP
2

Fetch E*Trade API Keys

Visit the E*Trade Developer Portal to obtain your production keys.

Configuration Mapping:
Locate config/config.ini.example in the downloaded folder.
Rename it to config.ini and paste your Consumer Key and Secret.
3

Execute System Scripts

Run these scripts to build the virtual environment and link your account.

cd $HOME/mcp/etradeMCP

# 1. Prepare environment (Run once)
./setup_env.sh

# 2. Authenticate (Run daily)
./etrade-auth.sh

SECURITY NOTE etrade-auth.sh is required at least once a day as E*Trade tokens expire regularly.

4

Configure Gemini & Claude

Tell your AI models where the E*Trade "brain" is located.

GEMINI SETTINGS: $HOME/.gemini/settings.json 
{                
 "mcpServers": {
  "etrade": {
    "command": "$HOME/mcp/etradeMCP/venv/bin/python",
    "args": ["$HOME/mcp/etradeMCP/src/mcp/server.py"],
    "env": { "PYTHONPATH": "$HOME/mcp/etradeMCP/" }
  }
 }
}
CLAUDE SETTINGS: $HOME/Library/Application Support/Claude/claude_desktop_config.json

5

Troubleshooting FAQ

Issue Solution
Module Not Found Run ./setup_env.sh again to ensure the virtual environment (venv) is built correctly.
Token Expired Run ./etrade-auth.sh. You must do this every 24 hours.
AI No Response Ensure the path in settings.json matches your actual $HOME path (e.g., /Users/name/mcp...).
